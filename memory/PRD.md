# PRD: Архів Кримінальних Серіалів

## Дата створення: 1 лютого 2025
## Остання оновлення: 1 лютого 2025 - Версія 5.0

## Оригінальна постановка задачі
Створити професійну атмосферну landing page українською мовою для відстеження серіалів True Crime про серійних вбивць та слідчих.

## Що реалізовано (Версія 5.0 - МОБІЛЬНА + SAFARI)

### ✅ Мобільна адаптивність (НОВЕ)
- 📱 **Responsive дизайн**: Адаптовано для екранів 320px - 1920px
- 👆 **Сенсорні екрани**: Збільшені кнопки та інтерактивні елементи для мобільних
- 📐 **Flexible layout**: Картки, таби та форми адаптуються до ширини екрану
- 🎨 **Оптимізація**: Приховано SVG-нитки на мобільних для кращої продуктивності
- 🔤 **Читабельність**: Зменшені шрифти зі збереженням чіткості на малих екранах

### ✅ Safari та приватний режим (НОВЕ)
- 🔒 **Перевірка LocalStorage**: Автоматична детекція доступності
- ⚠️ **Попередження користувача**: Червоний банер при недоступності збереження
- 💾 **Безпечне збереження**: Try-catch обробка помилок LocalStorage
- 🍎 **Apple meta-теги**: Оптимізація для iOS та Safari

### ✅ Містичний заголовок слідчів
- Жовті імена "MARIA × YAROSLAV" з ефектом мерехтіння
- Червона рамка з пульсуючими знаками ⚠
- Підпис "ДЕПАРТАМЕНТ СЕРІЙНИХ ЗЛОЧИНІВ"
- Responsive розміри для мобільних

### ✅ Навігація з табами
- "АРХІВ РОЗСЛІДУВАНЬ" / "СПИСОК БАЖАНЬ"
- Лічильники серіалів
- Вертикальне розміщення на мобільних

### ✅ Рейтингова система
- Доступна для всіх серіалів (0-10)
- Оптимізований слайдер для сенсорних екранів

- **Множинні нотатки** від Maria (рожева) та Yaroslav (синя)

## Технічні деталі

### Структура даних
```javascript
{
  id: string,
  title: string,
  watched: boolean,
  rating: number (0-10),
  notes: [
    {
      author: 'Maria' | 'Yaroslav',
      text: string,
      timestamp: ISO string
    }
  ]
}
```

### Responsive Breakpoints
- Desktop: > 768px
- Mobile: ≤ 768px
- Extra small: ≤ 375px

### Браузерна сумісність
- ✅ Chrome/Edge (desktop + mobile)
- ✅ Firefox (desktop + mobile)
- ✅ Safari (desktop + mobile + приватний режим)
- ✅ Safari iOS

## Обмеження LocalStorage
⚠️ **ВАЖЛИВО**: LocalStorage зберігає дані локально на пристрої:
- Різні браузери = різні дані
- Різні пристрої = різні дані  
- Приватний режим = дані не зберігаються
- Очищення кешу = втрата даних

Для синхронізації між пристроями потрібен backend (MongoDB + API).
