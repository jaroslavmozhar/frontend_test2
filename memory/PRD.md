# PRD: Архів Кримінальних Серіалів

## Дата створення: 1 лютого 2025

## Оригінальна постановка задачі
Створити професійну атмосферну landing page українською мовою для відстеження серіалів True Crime про серійних вбивць та слідчих.

### Дизайн та атмосфера
- **Візуальний стиль**: Темна естетика "Crime Scene"
- **Кольори**: Темний фон (чорний/темно-сірий) з червоними та жовтими акцентами
- **Візуальні елементи**: Детективна дошка з червоними нитками, відбитки пальців, зернисті текстури
- **Персоналізація**: "Слідчі: Maria та Yaroslav" шрифтом друкарської машинки

### Основний функціонал
1. Додавання серіалів через текстове поле
2. Список серіалів у вигляді "Досьє"
3. Чекбокс для позначення "Розкрито" (Переглянуто)
4. Рейтингова система 1-10 для переглянутих серіалів
5. Текстова область для нотаток
6. Збереження даних через LocalStorage

## Архітектура

### Технологічний стек
- **Frontend**: React 19.0.0
- **Стилізація**: Custom CSS (crime-theme.css)
- **Компоненти**: Shadcn UI (за потреби)
- **Зберігання даних**: LocalStorage
- **Роутинг**: React Router DOM

## Що реалізовано (1 лютого 2025)

### ✅ Фронтенд з повним функціоналом (Версія 4.0 - ЖУРНАЛ РОЗСЛІДУВАННЯ)
- **Містичний заголовок слідчів** з анімаціями:
  - Жовті імена "MARIA × YAROSLAV" з ефектом мерехтіння
  - Червона рамка з пульсуючими жовтими знаками небезпеки ⚠
  - Підпис "ДЕПАРТАМЕНТ СЕРІЙНИХ ЗЛОЧИНІВ"
  - Glow-ефект навколо заголовка
  
- **Навігація з табами**:
  - "АРХІВ РОЗСЛІДУВАНЬ" - переглянуті серіали
  - "СПИСОК БАЖАНЬ" - серіали для майбутнього перегляду
  - Лічильники кількості серіалів на кожному табі
  
- **Рейтингова система**:
  - ⭐ Доступна для ВСІХ серіалів (0-10)
  - Автоматичне збереження при зміні
  
- **ЖУРНАЛ РОЗСЛІДУВАННЯ (НОВА ФУНКЦІЯ)**:
  - 📝 **Множинні нотатки**: Кожен слідчий може додавати необмежену кількість записів
  - 👤 **Персоналізація автора**: 
    - MARIA (рожева рамка #ff6b9d, градієнт справа)
    - YAROSLAV (синя рамка #4a9eff, градієнт справа)
  - 🕐 **Часова мітка**: Дата і час створення кожного запису (формат: ДД.ММ.РРРР, ГГ:ХХ)
  - ✏️ **Вибір автора**: Радіо-кнопки для вибору Maria або Yaroslav перед додаванням
  - 🗑️ **Видалення записів**: Кнопка ✕ на кожному записі з підтвердженням
  - 💬 **Діалог слідчих**: Візуальна різниця між авторами створює ефект спілкування
  - 📋 **Порожній стан**: "Розслідування розпочато. Додайте першу нотатку"
  - 💾 **Автозбереження**: Всі записи зберігаються як масив в LocalStorage
  - 📜 **Прокручування**: Журнал прокручується при великій кількості записів (max-height: 400px)
  
- **Функція видалення**:
  - Кнопка ✕ у правому верхньому куті кожної картки
  - Підтвердження перед видаленням досьє
  
- **Базові функції**:
  - Темна детективна тема з червоними та жовтими акцентами
  - Сітка детективної дошки з червоними нитками та пінезами
  - Форма додавання нових серіалів
  - Картки у вигляді "Досьє"
  - Чекбокси для позначення переглянутих
  - Збереження в LocalStorage
  - Responsive дизайн
